# 版图 · 美股热力图

不用登录、没有弹窗的美股热力图。按板块 → 行业 → 个股展开：矩形面积代表市值（或当日成交额），颜色代表所选区间的涨跌幅。

- 股票池：标普 500、纳指 100、道指 30，以及全市场（美国上市、市值 10 亿美元以上，含 ADR 与跨境上市公司）
- 区间：今日、盘前、盘后、5 日、1 月、3 月、年初至今、1 年
- 支持红涨绿跌 / 绿涨红跌两种配色；另有色觉友好色板，用赭石与花青替代红绿
- 底部图例同时是涨跌分布直方图：悬停某一档会在图上高亮对应个股，点击可锁定
- 点击板块或个股逐级放大，按 Esc 或右键返回上一级；按 `/` 搜索
- 视图状态（股票池、区间、面积口径、放大位置）写在 URL 里，可以直接分享

## 架构：按需取数，没有访问就不取

```
浏览器
   │
   ▼
Workers Caching（分层缓存 + 请求合并 + stale-while-revalidate）── 命中：不运行 Worker
   │ 未命中
   ▼
Worker ── KV 中的数据未过期 ──► 直接返回
   │ 已过期
   ▼
TradingView scanner（主）/ Nasdaq screener（备） ──► 校验 ──► 写回 KV ──► 返回
```

- **没有 Cron，也没有后台轮询。** 上游只会在「有请求进来、且缓存和 KV 里的数据都已过期」时才被访问。
- **数据过期时间按交易时段计算**（`shared/market.ts` → `quotesExpiry`）：盘中 60 秒，盘前盘后 5 分钟。收盘约 20 分钟后，数据视为当日最终版，有效期一直延续到下一个交易日的盘前，所以夜间、周末和节假日无论访问量多少，都不会访问上游。
- **数据按变化频率拆成两份**：`meta`（名称、板块、行业、指数成分）每个交易日只刷新一次；`quotes`（纯数字行情）按上面的规则刷新。浏览器拿到两份后在本地拼接。
- **多层防护，避免重复请求上游**：
  - Workers Caching 默认分层缓存，并按缓存键合并并发请求，一波突发访问只会运行一次 Worker。
  - 同一 isolate 内的并发刷新合并成一次（single flight）。
  - 上游失败后 30 秒内不再重试，期间直接返回旧数据。
- **写入前先校验**：行数不得少于 1000、不得比上一份少 20% 以上、今日涨跌缺失不得超过 10%；不合格就不覆盖。上游失败时返回最后一份数据，并带上 `x-data-stale` 响应头。
- **备用数据源**：TradingView 失败时先返回旧数据。只有当 KV 里的数据早于最近一个交易日，且 Nasdaq 确实有更新的收盘数据时，才改用 Nasdaq 的今日涨跌。

### 免费版额度

| 限额（Workers Free） | 本项目的用量 |
|---|---|
| 每次调用 CPU 10ms | 本地用真实代码重放上游响应测得：刷新行情中位数约 4.4ms，刷新基础信息约 6ms；缓存命中时不运行 Worker。冷启动的 isolate 第一次运行可能偏高，Cloudflare 对偶发超限有一定容忍 |
| KV 每天 1000 次写入 | 只在刷新时写入。即使整天持续有人访问，也只有约 500 次（盘中每分钟 1 次，盘前盘后每 5 分钟 1 次），外加每天 1 次基础信息 |
| KV 每天 10 万次读取 | 只在缓存未命中时读取 |
| 每次调用 50 个子请求 | 刷新行情 2 个，刷新基础信息 5 个 |

主要的性能开销在解析上游的 JSON（行情约 470KB）。如果还要再压，可以把全市场的市值门槛从 10 亿美元提到 20 亿美元（`worker/tradingview.ts` 里的 `UNIVERSE`），行数会减少约两成。

## 数据接口

`/api/quotes`、`/api/meta`、`/api/status` 只供本站页面使用，不是公开 API：不发跨域头，没有接口目录，也不保证格式稳定。行情数据不归本项目所有，不对外再分发。

- `quotes` 和 `meta` 带 `ETag`，支持 `If-None-Match`；`Cache-Control` 随数据有效期变化。响应头里的 `x-data-fetched-at`、`x-data-expires-at`、`x-data-source`（上游失败时还有 `x-data-stale`）用于排查。
- `status` 只返回数据新鲜度和当前交易时段，不含行情，也不会触发刷新。
- 为防止有人用随机参数绕过缓存，带任何查询参数的请求一律返回 400。

## 开发

```sh
pnpm install
pnpm dev          # Vite + workerd；第一次请求会现取数据（约 2 秒），之后读 KV
pnpm test
pnpm typecheck
```

本地开发不会模拟 Workers Caching，每个请求都会运行 Worker，但 KV 的过期判断照常生效，所以不会因此频繁访问上游。

## 部署（Cloudflare Workers）

```sh
pnpm deploy   # 第一次部署会自动创建 KV namespace，并把 id 写回 wrangler.jsonc
```

部署前需要知道：

- `cache.enabled` 需要 Wrangler 4.69 或更高版本（当前用的是 4.151）。
- 两个上游目前只在本地环境调通过，从 Cloudflare 出口发出的请求会不会被拦截，需要部署后再验证。

## 数据来源与许可

TradingView scanner 和 Nasdaq screener 都是网站内部接口，没有公开文档和 SLA，两家的条款也都限制自动化采集和再分发。本项目只在自己的页面上展示数据，不提供数据接口，适合个人使用；若要长期公开运营，应换成有授权的数据源。数据源适配代码集中在 `worker/tradingview.ts` 和 `worker/nasdaq.ts`。

## 设计

- 月白底色（`#f1f7f8`）配黛色文字（`#1c232d`），不走暗色终端风
- 涨跌色取自国画颜料：朱砂、石绿；色觉友好色板用赭石、花青。色阶在 OKLCH 里插值，饱和度先于明度到位，中等涨跌幅不会发灰
- 字体用 Mona Sans 可变字体：窄格子自动改用窄体（宽度轴 75%–100%），尽量让代码以更大字号显示
- 首次加载时颜色从中性灰晕开；切换区间时颜色渐变过渡；放大时整块推近，其他格子顺势移出画面
