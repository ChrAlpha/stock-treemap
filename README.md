# 版图 · 全球股市热力图

不用登录、没有弹窗的股市热力图，覆盖美股、A 股、港股、日股、韩股、台股、印度、新加坡、澳洲、英国、德国、法国、加拿大 13 个市场。按板块 → 行业 → 个股展开：矩形面积代表市值（或当日成交额），颜色代表所选区间的涨跌幅。

- 每个市场有自己的股票池：指数成分（标普 500、沪深 300、恒生指数、恒生科技、日经 225、KOSPI 200、台湾 50、Nifty 50、富时 100、DAX、CAC 40 等）和按市值截取的全市场
- 区间：今日、5 日、1 月、3 月、年初至今、1 年；美股另有盘前、盘后
- A 股、港股、台股的格子写公司名（港股、台股为繁体），其他市场写代码；市值和成交额按各市场本币计
- 支持红涨绿跌 / 绿涨红跌两种配色；另有色觉友好色板，用赭石与花青替代红绿
- 底部图例同时是涨跌分布直方图：悬停某一档会在图上高亮对应个股，点击可锁定
- 点击板块或个股逐级放大，按 Esc 或右键返回上一级；按 `/` 搜索（中文名单字即可）
- 视图状态（市场、股票池、区间、面积口径、放大位置）写在 URL 里，可以直接分享；直接打开首页时回到上次看的市场

几处需要知道的口径：

- 一家公司在一个市场只画一格。日本、印度、英国、德国、法国、韩国、台湾、新加坡只取主上市地；A 股、港股、澳洲、加拿大则按交易所和币种筛选，否则数据源会把 H 股、阿里巴巴、汇丰、中芯国际 A 股、力拓、Shopify 这类"主上市地在别处"的大公司漏掉。
- 市值是公司总市值：港股的 H 股、A 股里的 A+H 公司、澳洲的力拓都按整家公司计，和数据源自己的热力图一致。
- 指数成分由数据源提供。德国、法国、英国、澳洲各有几只成分股的主上市地在别处（例如空客、林德），不出现在该市场的图上。

## 开发

```sh
pnpm install
pnpm dev          # Vite + workerd；每个市场第一次请求会现取数据（约 1–2 秒），之后读 KV
pnpm test
pnpm typecheck
```

本地开发不会模拟 Workers Caching，每个请求都会运行 Worker，但 KV 的过期判断照常生效，所以不会因此频繁访问上游。

## 部署

两种方式跑的是同一份 Worker 代码，区别只在前面有没有 Cloudflare 的缓存、数据存在哪里。

### Cloudflare Workers

```sh
pnpm deploy   # 第一次部署会自动创建 KV namespace，并把 id 写回 wrangler.jsonc
```

- 绑定自定义域名：在环境变量或 `.env.local` 里设置 `CUSTOM_DOMAIN=stock.example.com`（多个用逗号分隔），部署时 Wrangler 会创建 DNS 记录和证书，并关闭 workers.dev。不设置则只部署到 workers.dev。
- `cache.enabled` 需要 Wrangler 4.69 或更高版本（当前用的是 4.151）。
- 两个上游目前只在本地环境调通过，从 Cloudflare 出口发出的请求会不会被拦截，需要部署后再验证。

也可以交给 GitHub Actions：发布 GitHub Release 时，`.github/workflows/release.yml` 会测试、构建并部署。需要在仓库设置里配置：

| 类型 | 名称 | 说明 |
|---|---|---|
| Secret | `CLOUDFLARE_API_TOKEN` | 该 Worker 的 Workers Editor 权限，加上域名所在 zone 的 Workers Routes Write |
| Variable | `CLOUDFLARE_ACCOUNT_ID` | 不设置则跳过 Workers 部署 |
| Variable | `CUSTOM_DOMAIN` | 同上；不设置会部署到 workers.dev |

### 自部署（Docker / Node）

```sh
docker compose up -d   # 本地构建并启动，http://127.0.0.1:3000
```

每次发布 Release 也会推送多架构镜像（linux/amd64、linux/arm64）到 GitHub Container Registry，可以直接拉取：

```sh
docker run -d -p 127.0.0.1:3000:3000 -v stock-treemap:/data ghcr.io/chralpha/stock-treemap
```

不用 Docker 时需要 Node 24：

```sh
pnpm install
pnpm build:server   # 构建页面和服务端，产物在 dist/
pnpm start
```

| 环境变量 | 默认值 | 说明 |
|---|---|---|
| `PORT` | `3000` | 监听端口 |
| `HOST` | `127.0.0.1`（镜像内为 `0.0.0.0`） | 监听地址 |
| `DATA_DIR` | `data`（镜像内为 `/data`） | 行情数据的存放目录，重启后不必重新取数 |

- KV 换成了内存加本地文件，一个数据目录只能由一个进程使用。
- 前面没有 Cloudflare 的缓存，但过期判断和请求合并都在服务端里，每个市场在每个有效期内仍然最多访问上游一次。
- 服务只监听本机；对外访问（反向代理、HTTPS、隧道）需要自行配置。

## 设计

- 月白底色（`#f1f7f8`）配黛色文字（`#1c232d`），不走暗色终端风
- 涨跌色取自国画颜料：朱砂、石绿；色觉友好色板用赭石、花青。色阶在 OKLCH 里插值，饱和度先于明度到位，中等涨跌幅不会发灰
- 字体用 Mona Sans 可变字体：窄格子自动改用窄体（宽度轴 75%–100%），尽量让代码以更大字号显示
- 首次加载时颜色从中性灰晕开；切换区间时颜色渐变过渡；放大时整块推近，其他格子顺势移出画面
